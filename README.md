# Jobs

A repository for sharing job opportunities through GitHub Issues. Job postings and labels are written in English to make opportunities easy to find and browse.

## Job opportunities

Browse [open positions](https://github.com/velrino/jobs/issues) or [create a job posting](https://github.com/velrino/jobs/issues/new).

Each issue should include:

- Job title and company name.
- Location and work arrangement: remote, hybrid, or on-site.
- Employment type, requirements, and compensation when available.
- A link to the original posting or application page.
- Relevant English labels for the role, seniority, location, and work arrangement.

Suggested title: `[Company] Job Title — Location / Remote`

Example labels: `engineering`, `senior`, `remote`, `full-time`.
